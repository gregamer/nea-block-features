== Description ==
Vtičnik doda možnosti vidnosti blokov, obrat stolpcev na mobilnem, povezavo na bloku Column, shortcode za shranjen vzorec in višji prag za pomanjšanje naloženih slik.

Vidnost blokov, obrat stolpcev, povezava stolpca in shortcode [show_pattern] so v nastavitvah pod menijem neAGENCIJA in so privzeto vklopljeni. Prag za pomanjšanje slik je vedno vklopljen (6000 px namesto WordPressovih 2560 px) in ne spremeni omejitve velikosti nalaganja.
